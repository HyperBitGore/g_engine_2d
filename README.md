# g_engine_2d
 Win32 header only game engine using modern OpenGL

To use in your own projects just throw it in include and add these Libs


For Win32
 - gdi32 
 - user32 
 - opengl32 
 - ole32

For Linux
 - X11
 - OpenGL
 - Xkb
 - ALSA

 Current Features
  - Modern OpenGL Context creation
  - TTF font loading and rendering
      - Support for common formats
      - No hinting support yet
  - 2D Image drawing
  - 2D Primitive drawing
  - PNG and BMP loading
      - PNG supports most file encoding modes
      - BMP supports majority of encoding modes
  - Audio Support
     - Audio playing
     - WAV file loading
     - Stream audio from files
     - Play audio from seperate thread
  - Abstracted keyboard/mouse input
  - Fullscreen window
  - Mouse control
      - Hide cursor
      - Capture cursor in window
